# Tecnologias por projeto

Onde o Lucas usou cada tecnologia. Uma ferramenta aparecer aqui significa que ele já trabalhou com ela em pelo menos um projeto, não que ele a domina.

## QA e testes — onde usou
- Jira: projeto EventHub QA (gestão de bugs e do fluxo de testes).
- Postman: testes de API (citado pelo Lucas como ferramenta de QA).
- Playwright: testes de ponta a ponta (E2E) deste portfólio.
- Pytest: testes do ParkFinder, do e-commerce LabDeProg e do RideFleet.
- Vitest: testes unitários deste portfólio.
- Swagger/OpenAPI: documentação da API do ParkFinder e do RideFleet.

## Linguagens — onde usou
- Python: ParkFinder, AlphaPulse, Leukemia Classification, LabDeProg, RideFleet e os jogos em Pygame.
- TypeScript: aplicativo do ParkFinder e este portfólio.
- JavaScript: Agenda UFV, LabDeProg e o front-end do RideFleet.
- PHP: Agenda UFV.
- C: algoritmos de ordenação da graduação.
- HTML5 e CSS3: Agenda UFV e LabDeProg.

## Inteligência artificial — onde usou
- PyTorch: AlphaPulse (LSTM, Bi-LSTM, CNN, Transformer) e Leukemia Classification (ResNet50, DenseNet121, EfficientNet-B3).
- Hugging Face Transformers: fine-tuning do FinBERT-PT-BR no AlphaPulse.
- scikit-learn, pandas, NumPy e Matplotlib: AlphaPulse e Leukemia Classification.
- Jupyter e Kaggle: Leukemia Classification.
- Streamlit: aplicação web do AlphaPulse.
- Gemini: assistente com RAG deste portfólio.

## Back-end e dados — onde usou
- FastAPI, Pydantic, SQLAlchemy, Alembic, JWT, PostgreSQL e PostGIS: back-end do ParkFinder.
- Django e MySQL: e-commerce LabDeProg.
- FastAPI, Pydantic, SQLAlchemy (assíncrono) e PostgreSQL: back-end do RideFleet.
- Redis (Redis Streams e script Lua): filas de corridas e relógio de Lamport do RideFleet.
- SQLite: AlphaPulse (banco da coleta de notícias), LabDeProg e testes do RideFleet.
- Node.js: ambiente do portfólio e do aplicativo Expo.

## Mobile, web e DevOps — onde usou
- React Native, Expo e OpenStreetMap: aplicativo do ParkFinder.
- React e Next.js: este portfólio. React com Vite: front-end do RideFleet.
- Docker e Docker Compose: ParkFinder, LabDeProg e RideFleet.
- Nginx (load balancer), Prometheus e Grafana (métricas e dashboards): RideFleet.
- GitHub Actions: CI deste portfólio.
- Git e GitHub: todos os projetos.
