# Habilidades técnicas do Lucas

## Importante: usou não é o mesmo que domina
As tecnologias listadas aqui são ferramentas que o Lucas já usou em projetos. Isso não quer dizer que ele domina todas: algumas ele usa com frequência, outras usou em um único projeto ou trabalho em grupo. Para saber em qual projeto cada ferramenta foi usada, veja a seção "Tecnologias por projeto". Para saber o nível de domínio em algo específico, o melhor é perguntar diretamente para ele.

## QA e testes de software
Fundamentos de teste de software, criação de cenários e casos de teste, testes funcionais, negativos, de regressão e exploratórios, reteste, reporte de bugs (com passos de reprodução, resultado esperado e resultado obtido), severidade e prioridade, análise de valor limite e particionamento de equivalência. Ferramentas já usadas: Jira, Postman, Playwright, Pytest, Vitest e Swagger/OpenAPI.

## Inteligência artificial e machine learning
O Lucas tem experiência recente com IA em projetos acadêmicos em grupo e no próprio portfólio: fine-tuning de modelos de linguagem (FinBERT-PT-BR com Hugging Face Transformers), classificação de imagens com redes convolucionais e transfer learning (ResNet50, DenseNet121, EfficientNet-B3), modelos de séries temporais (LSTM, Bi-LSTM, Transformer), modelos clássicos (SVM, regressão logística, MLP), aumento de dados, avaliação rigorosa (validação cruzada, walk-forward, F1-macro, ROC-AUC, matriz de confusão, testes de significância como McNemar), cuidado com vazamento de dados e RAG (Retrieval-Augmented Generation) com o Gemini. Ferramentas já usadas: PyTorch, Hugging Face, scikit-learn, pandas, NumPy, Matplotlib, Jupyter, Streamlit, Gemini e Kaggle.

## Back-end, APIs e bancos de dados
REST APIs, HTTP, JSON, autenticação com JWT, consultas espaciais com PostGIS e migrações de banco. Ferramentas já usadas: FastAPI, Pydantic, SQLAlchemy, Alembic, Django, Django REST Framework, Node.js, PostgreSQL, PostGIS, MySQL e SQLite.

## Mobile e web
Ferramentas já usadas: React Native, Expo, React, Next.js, OpenStreetMap (mapas), HTML5, CSS3 e JavaScript.

## Linguagens de programação
Python, TypeScript, JavaScript, C, PHP e SQL.

## Ferramentas, DevOps e engenharia de software
Git, GitHub, GitHub Actions (CI/CD), Docker, Docker Compose, Jira, Postman, metodologias ágeis, UML, documentação, estruturas de dados e algoritmos.

## Suporte de TI
Manutenção de computadores, diagnóstico de hardware e software, montagem de desktops e notebooks, suporte técnico e atendimento ao cliente.

## Habilidades comportamentais
Perfil analítico, comunicação, trabalho em equipe, adaptabilidade, autogestão e facilidade para aprender coisas novas.
